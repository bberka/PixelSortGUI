# Drift roadmap

Status: settled for first release, 2026-11-24. Companion specs: [product.md](product.md), [engine.md](engine.md), [persistence.md](persistence.md), [../../DESIGN.md](../../DESIGN.md), [decisions.md](decisions.md). Workflow rules: [workflow.md](../agents/workflow.md), [roster.md](../agents/roster.md), [tooling.md](../agents/tooling.md).

## Conventions

- **One task, one worktree, one pull request.** Every task below is sized so one subagent can implement, test, and open a PR in a single session.
- **Model tiers** follow [roster.md](../agents/roster.md): **GPT Luna** for light tasks and small-diff reviews; **Gemini 4 Neon (Antigravity, low or medium)** for standard and larger tasks; **Claude Fable (low or medium)** used sparingly only where `roster.md` justifies it (cross-cutting design, hardest engine work, or escalation after a Neon attempt fails), with the reason stated on the task; **deepseek-flash** for research and bulk reading. Every PR is reviewed by a different model from its author.
- **Parallelism:** Tasks that share the same dependency prerequisite and touch disjoint areas are marked **Parallel with** so the lead agent can fan them out across separate worktrees.
- **Verification:** Every task runs `vp run check` and `vp run build` once M0 lands, plus the task-specific verification listed below. UI tasks require screenshots in a desktop browser at `390 × 844`, `820 × 1180`, and `1440 × 900` (layout check only) in both Light and True Black themes, uploaded to the pull request.

## Later work (beyond v0.5.0)

Each item below requires its own spec in `docs/specs/` (or `docs/specs/effects/`) before implementation starts (moved items retain their existing spec sections under "Later"). Ordered roughly by user value and architectural sequence:

1. **Mobile, tablet, and Safari acceptance (formerly `S2`):** Real-device acceptance on phones, tablets, and Safari; the iOS > 16.78 MP decode/export path (tiled decode, `fflate` streaming PNG writer, on-demand Wasm JPEG encoder, 24 MP mobile limit, [engine.md section 16.2](engine.md#162-ios-canvas-limit-decode-and-export-path)); and Safari 7-day storage eviction / Home Screen warnings ([persistence.md section 8.4.5](persistence.md#845-safari-7-day-eviction-warning-later)).
3. **Masks and on-canvas tools (`EffectStack` `schemaVersion: 2`):** Per-instance 8-bit brush/luminance/imported masks following [engine.md section 5.6](engine.md#56-masks-later-semantics-fixed-now), using the reserved on-canvas tool slot ([engine.md section 4.7](engine.md#47-on-canvas-tool-slot-reserved-for-later), [DESIGN.md section 7.1](../../DESIGN.md#71-on-canvas-tool-slot-reserved-for-later)). Adds a `masks` IndexedDB store. Also covers region cutout if requested in Q11.
4. **`pixelSort` extensions:** smooth grouping and non-linear paths (concentric rectangles, circles, spirals, random walks, tiles).
5. **Editing comfort & extended colour pipelines:** Compare against any history entry, clipboard paste, batch export, Safari WebP export via Wasm, 16-bit / Display P3 pipelines.
6. **WebGPU acceleration:** Plug into `src/engine/gpu/` per [engine.md section 12](engine.md#12-where-webgpu-plugs-in-later). First target: axis-aligned `pixelSort` for lines ≤ 4,096 px using per-line workgroups, parallel prefix/suffix scan selection and interval splitting, and bitonic sorting network in 16 KiB workgroup memory (clean-room or MIT-attributed port of `ruccho/BitonicPixelSorter` with notice in `THIRD-PARTY-NOTICES.md`). Must pass bit-exact golden tests before enabling for `settle`/`full`; startup smoke test and CPU fallback on device loss remain mandatory.
7. **Motion (GIF and video):** Introduce a frame-source and keyframe-interpolation layer above the pure `renderStack` pipeline (parameter animation over N frames, GIF/video frame-by-frame input, WebCodecs `VideoEncoder` + client-side muxer or Wasm GIF encoder). Zero changes to still-image effect kernels.
8. **Native packaging with Tauri:** Package the static `dist/` build with **Tauri** for native desktop and mobile apps. Because Tauri uses the system webview (WebKit on iOS and macOS, WebKitGTK on Linux), the iOS canvas-limit path in item 2 is required before shipping Apple native builds ([decisions.md D13](decisions.md#d13-tauri-for-later-native-packaging-2026-11-24)).
9. **Manual Firefox persistence spot-checks (owner):** When `T3.2` and `T4.5` land, manually verify in a real Firefox Private Browsing window (import, Settings → Storage display, clean session clear on close) and in a normal Firefox window (non-blocking native `persist()` permission doorhanger on first import, `"Storage protection: Persistent"` after Allow, and optional real `QuotaExceededError` check); see [spike-s3-persistence.md](../research/spike-s3-persistence.md#manual-checks-for-the-owner).
